# /gs-session-start — восстановление контекста

Память Claude машинно-локальна; переносимый контекст живёт в репо. Порядок:

1. **Прочитать** `CLAUDE.md` (загружен автоматически) и **самый свежий**
   `Docs/plans/*-SESSION-HANDOFF.md` (`ls Docs/plans/ | grep HANDOFF | tail -1`).
2. **Git:** `git status --short`, `git log --oneline -12`, `gh pr list` — что открыто, что не смержено.
3. **Прод (read-only):** `make prod-status`, `make prod-schema` (ревизия Alembic должна равняться
   последнему файлу в `migrations/versions/`), `make prod-grep TAG='ERROR|Traceback|STALE_SHEET|SHEET STUCK'`.
4. **Календарь домена:** какой сейчас учебный год (сен–дек → year, янв–авг → year-1), не летний ли режим
   (01.06–25.08), не граница ли четверти — многие баги завязаны на даты (см. CLAUDE.md §26e).
5. Коротко резюмировать владельцу: что в проде, что открыто, что предлагаю делать первым.

Не начинать кодить до шага 5. Не мержить и не пушить в `main` без явной команды владельца (push в main = деплой).
