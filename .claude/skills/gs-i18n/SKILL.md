# /gs-i18n — тексты пользователю

- Любая строка пользователю — через `t("key", lang, **kwargs)` (`src/i18n.py`). Захардкоженный русский в
  коде = баг.
- **Три локали бота синхронны:** `src/locales/{ru,uz,en}.json` — новый ключ добавлять во все три, с
  **одинаковым набором плейсхолдеров** `{name}`; проверяет `tests/test_locales_sync.py`.
- **WebApp — свои локали** `webapp/static/locales/{ru,uz,en}.json` (не дублируют бота), тест
  `tests/test_webapp_locales_sync.py`.
- Формат сообщений — **HTML** (`parse_mode='HTML'`): `<b>`, `<code>`, `<a href>`; экранировать `<`, `&`
  в пользовательских данных. Markdown не используется.
- Ключи для админ-группы (support-карточки, алерты админу `alert_*`) — тоже в трёх локалях (админ может
  сменить язык), но содержательно на русском допустимо.
- Уведомления, которые могут уйти в очередь тихих часов, теряют inline-кнопки → текст должен содержать
  словесный путь («Меню → Семья → 🔗 Сменить ссылку»).
- Именование ключей: `<домен>_<смысл>` (`relink_nudge_new_year`, `alert_sheet_stale`, `child_url_invalid`).
- Узбекский — латиница (`o'quv yili`, апостроф `'`), английский — нейтральный.

Проверка без Docker: `make check` (валидность JSON) + `make test-k K=locales` (синхронность).
