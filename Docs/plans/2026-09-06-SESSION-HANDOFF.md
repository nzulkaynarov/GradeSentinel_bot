## Что сделано

**Апгрейд библиотеки (#126).** pyTelegramBotAPI 4.21.0 → 4.36.1, то есть Bot API 7.4 → 10.2;
актуальный Bot API — 10.3. Кода не касается. Проверено, что все 20 вызываемых методов на месте,
`disable_web_page_preview` (устарел в 7.0) всё ещё принимается, платёжные сигнатуры совместимы.
Лок вырос на 8 пакетов: `aiohttp` стал обязательной зависимостью апстрима — на RAM не влияет,
`async_telebot` не импортируется.

**Ресерч и план (#127).** `Docs/plans/2026-09-05-telegram-api-modernization.md`: разрыв версий,
аудит наших вызовов, каталог фич по приоритету, порядок работ. Три находки:
Telegram Stars уже реализованы, но `STARS_ENABLED` на проде пустой; `subscription_period` есть
только у `create_invoice_link`, не у `send_invoice`; `isVersionAtLeast` не использовался нигде.

**Редизайн Mini App (#128–#132), пять PR подряд, каждый — рабочий дашборд.** Макет на четыре
вкладки был согласован в прошлой сессии, но жил только артбордами вне git (артефакт
`GradeSentinel Mini App`). Перенесён в код:

- каркас: четыре панели, нижняя навигация, `safeAreaInset`, `disableVerticalSwipes`;
- «Сегодня»: одна карточка-ответ вместо плитки из четырёх KPI, лента по дням;
- «Предметы»: список за период на ожившей `renderSubjectsList` (висела мёртвой), четвертные
  переехали в «Итоги»;
- «Итоги»: тренд словом вместо стрелки, убран подвал, дублировавший «Предметы»;
- «Чат»: быстрые вопросы, кнопка-иконка с переводимым `aria-label`, полноэкранный режим,
  CloudStorage вместо `localStorage` для отметки «что уже видел».

Конвенции закреплены в CLAUDE.md — §26k (структура вкладок, что где живёт) и §26l (каждый вызов
SDK за проверкой версии).

## Чего проверка не покрыла

Тесты выросли с 640 до 664 и впервые покрывают разметку дашборда: `tests/test_webapp_tabs.py`
проверяет соответствие панелей и карты `TAB_VIEWS`, наличие переводов у каждого `data-i18n`,
гейты версий SDK, раскрытие усечения. Отдельно каждый PR проверялся рендером через Flask (DOM
без незакрытых тегов) и на проде — что сервер отдаёт нужный HTML.

**Ни один из этих способов не показывает, как это выглядит на телефоне.** Не проверено: налезает
ли таб-бар на последнюю карточку, правильно ли сел полноэкранный режим относительно выреза
камеры, читается ли лента и список предметов на реальном экране. Самое рискованное место —
`_requestFullscreen()` в #132: он убирает шапку Telegram, и при неверном верхнем отступе
приветствие окажется под статус-баром. Правится одной функцией, откат PR не нужен.

## Грабли этой сессии

- **Пайп съедает код выхода.** `docker compose build | tail -5` вернул 0, хотя сборка упала по
  таймауту PyPI; образ остался старым, и «640 passed» после апгрейда библиотеки прогнались против
  **старой** версии. Проверка стала действительной только после того, как версию в образе
  подтвердили явно. Правило: результат сборки читать по её коду выхода, а не по хвосту вывода.
- **Тест должен проверять требование, а не строку кода.** Honesty-тест на литерал
  `${shown} / ${total}` упал при смене механизма раскрытия усечения — упал правильно, но чинится
  переписыванием на смысл (видны оба числа, строка скрыта когда усечения нет), а не удалением.
- **Скоуп regex-теста по коду.** Тест «тренд словом, а не стрелкой» сначала ловил стрелку в
  drill-down, которую никто не трогал: `split("function X")[1]` берёт файл до конца, нужен ещё
  `.split("\\nfunction ")[0]`.
- **Два прод-сервера с одинаковым hostname.** `vps` (176.101.56.141, бот и webapp) и `vps-db`
  (170.168.6.209, PostgreSQL) оба зовутся `vps00249.eskiz.uz` — различать только по IP. Алиасы
  добавлены в `~/.ssh/config`, цели `make prod-*` работают.
- **Память машинно-локальна и отстаёт.** На этой машине она была от 14.06 и не знала про
  PostgreSQL. Единственный надёжный источник — этот файл, `Docs/` и `CLAUDE.md`.
